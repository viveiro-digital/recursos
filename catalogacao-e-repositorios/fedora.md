[Fonte oficial](https://fedorarepository.org/)

Software de repositório de código aberto para preservação digital de longo prazo, com mais de 20 anos de desenvolvimento. A Lyrasis é a organização responsável. A versão atual é a 7.

Não tem interface para o público: funciona como camada de armazenamento de outros sistemas, como Islandora e Samvera.

## Funcionalidades

- Armazena qualquer tipo de objeto digital, com relações semânticas entre eles.
- Guarda os objetos no formato OCFL.
- APIs publicadas para integração com outros sistemas.

## Observações

- **Custo:** gratuito.
- **Instalação:** requer servidor próprio.
- **Conhecimento técnico:** administração de servidores.
- **Licença:** Apache 2.0.
