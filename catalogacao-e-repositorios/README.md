# Catalogação e repositórios

Softwares para catalogar, gerir e publicar coleções digitais.

- [AtoM — Access to Memory](atom.md): Software de descrição arquivística e acesso.
- [CollectiveAccess](collectiveaccess.md): Software de catalogação e publicação de coleções.
- [DSpace](dspace.md): Software para repositórios digitais.
- [Fedora](fedora.md): Base de repositório digital para infraestrutura especializada.
- [InvenioRDM](inveniordm.md): Plataforma de gestão de produtos de pesquisa.
- [Lenny](lenny.md): Biblioteca digital com recursos de acesso e empréstimo.
- [Mukurtu](mukurtu.md): Plataforma de gestão de patrimônio cultural em contextos comunitários.
- [Omeka S](omeka-s.md): Publicação de coleções digitais com suporte a vocabulários e relações.
- [Tainacan](tainacan.md): Gestão e publicação de acervos digitais em WordPress.
