[https://omeka.org/s/](https://omeka.org/s/)

Plataforma de publicação web para coleções digitais de patrimônio cultural, desenvolvida pela Digital Scholar. A mesma organização desenvolve o Omeka Classic, para um único site.

## Funcionalidades

- Vários sites a partir de uma única instalação.
- Publicação de itens com dados abertos ligados (*linked open data*) e vocabulários como o Dublin Core.
- Modelos de descrição compatíveis com a Digital Public Library of America (DPLA).
- Módulos para mapas, coleta de contribuições e importação, e temas responsivos.

## Observações

- **Custo:** gratuito.
- **Instalação:** requer servidor próprio.
- **Conhecimento técnico:** administração de servidores.
- **Licença:** GNU GPL 3.0.

## Leitura inicial baseada na fonte oficial

Esta não é uma avaliação de uso pelo Viveiro. A fonte oficial apresenta o Omeka S como uma plataforma web para instituições que publicam coleções culturais digitais, com vários sites em uma instalação, dados abertos ligados, módulos e temas responsivos.

Parece adequado quando diferentes projetos precisam compartilhar uma instalação e publicar coleções com apresentações próprias. A avaliação prática deve verificar quais módulos e configurações são necessários para cada acervo.
