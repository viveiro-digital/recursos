Visualizador de código aberto desenvolvido para compartilhar diferentes tipos de conteúdo na web. O projeto pode ser instalado como pacote npm e configurado para diferentes usos.

## Funcionalidades

- Exibição de imagens e PDFs.
- Exibição de arquivos 3D.
- Reprodução de áudio e vídeo.
- Instalação como pacote npm.
- Configuração por código e uso em diferentes cenários.

## Observações

- **Custo:** gratuito.
