[https://github.com/LibraryOfCongress/bagit-python](https://github.com/LibraryOfCongress/bagit-python)

Biblioteca Python e ferramenta de linha de comando da Library of Congress para trabalhar com pacotes no formato BagIt.

## Funcionalidades

- Criação de pacotes BagIt a partir de diretórios.
- Geração de manifestos com somas de verificação.
- Validação da estrutura e dos arquivos de um pacote.
- Uso como módulo Python em outros programas.

## Observações

- **Custo:** gratuito.
- **Instalação:** pacote Python, instalado com `pip`.
- **Conhecimento técnico:** uso do terminal.
- **Licença:** CC0 1.0.
