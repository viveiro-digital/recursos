Aplicação de código aberto e autohospedável para arquivar conteúdo da web. Salva cópias de páginas, arquivos de mídia e outros conteúdos em formatos legíveis por outros programas.

## Funcionalidades

- Importação de URLs, favoritos, histórico do navegador e feeds.
- Geração de cópias em HTML, PDF, PNG, texto, JSON e WARC.
- Interface web autohospedável e interface de linha de comando.
- API Python e API REST para integrações.
- Execução por Docker ou instalação como pacote Python.

## Observações

- **Custo:** gratuito.
- **Instalação:** requer servidor próprio.
- **Conhecimento técnico:** uso do terminal.
