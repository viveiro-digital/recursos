Visualizador web de código aberto para exibir e comparar imagens, com recursos de ampliação, rotação e anotações. O projeto pode ser instalado como pacote JavaScript ou incorporado a uma página web.

## Funcionalidades

- Exibição de várias imagens em uma mesma interface.
- Ampliação, redução e rotação das imagens.
- Comparação de imagens.
- Exibição de imagens com anotações.
- Instalação por `npm` ou `yarn`.

- **Conhecimento técnico:** uso do terminal.
