[Fonte oficial](https://www.rfc-editor.org/rfc/rfc9309)

Especificação do arquivo robots.txt. Um site usa esse arquivo para indicar a robôs de coleta, como buscadores e coletores de dados para treinamento de inteligência artificial, quais páginas não devem ser acessadas.

O cumprimento das regras depende de cada robô. A própria especificação afirma que o robots.txt não é um mecanismo de controle de acesso.
