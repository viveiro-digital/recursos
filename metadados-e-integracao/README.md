# Metadados e integração

Vocabulários, formatos e protocolos para descrever materiais e trocar dados entre sistemas.

- [BagIt — RFC 8493](bagit.md): Formato de pacotes com manifestos para transferir e verificar arquivos.
- [DCMI Metadata Terms (Dublin Core)](dcmi-metadata-terms.md): Vocabulário para descrever materiais.
- [FAIR Principles](fair-principles.md): Princípios para dados localizáveis, acessíveis, interoperáveis e reutilizáveis.
- [IIIF Presentation API 3.0](iiif-presentation-api.md): Descrição da apresentação de objetos compostos, como publicações com várias páginas.
- [OAI-PMH](oai-pmh.md): Protocolo de coleta de metadados entre sistemas.
- [OCFL — Oxford Common File Layout](ocfl.md): Organização de objetos digitais e suas versões no armazenamento.
- [PREMIS](premis.md): Metadados de preservação: objetos, eventos, agentes e direitos.
- [PROV-O (W3C)](prov-o.md): Modelo para registrar e compartilhar informações sobre origem e transformações.
- [Understanding Metadata (NISO)](understanding-metadata-niso.md): Introdução ao que são metadados e para que servem.
