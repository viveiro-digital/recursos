# Tratamento de arquivos

Ferramentas para limpar dados, identificar e validar formatos, processar, copiar e recuperar arquivos.

- [Archivematica](archivematica.md): Sistema para processamento e preservação digital.
- [DROID](droid.md): Identificação de formatos de arquivos digitais.
- [OCRmyPDF](ocrmypdf.md): Reconhecimento de texto em PDFs, para gerar versões pesquisáveis.
- [OpenRefine](openrefine.md): Limpeza, transformação e reconciliação de dados.
- [rclone](rclone.md): Transferência e sincronização de arquivos entre serviços de armazenamento.
- [restic](restic.md): Ferramenta de backup e restauração.
- [veraPDF](verapdf.md): Validação de PDFs conforme os perfis suportados.
