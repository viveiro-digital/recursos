[https://mediaarea.net/MediaInfo](https://mediaarea.net/MediaInfo)

Ferramenta que exibe dados técnicos e etiquetas de arquivos de áudio e vídeo. Inclui interfaces de linha de comando e gráficas.

## Funcionalidades

- Exibição de dados técnicos de arquivos de áudio e vídeo.
- Exibição de etiquetas e outros metadados.
- Interface de linha de comando.
- Interfaces gráficas para diferentes sistemas operacionais.
- Biblioteca MediaInfoLib para integração com outros programas.

## Observações

- **Custo:** gratuito.
- **Instalação:** programa para computador (Linux, macOS, Windows e outros sistemas).
- **Conhecimento técnico:** não requer (interface gráfica) ou uso do terminal.
- **Licença:** BSD 2-Clause.
