[https://openrefine.org/](https://openrefine.org/)

Ferramenta de código aberto para limpar dados desorganizados e convertê-los entre formatos. Os dados são processados no próprio computador.

## Funcionalidades

- Facetas para filtrar grandes conjuntos de dados.
- Agrupamento (*clustering*) de valores parecidos, como um nome escrito de formas diferentes.
- Reconciliação com bases externas, como o Wikidata.
- Histórico ilimitado para desfazer e refazer alterações.

## Observações

- **Custo:** gratuito.
- **Instalação:** programa para computador, usado pelo navegador.
- **Conhecimento técnico:** não requer programação.
- **Licença:** BSD 3-Clause.

## Leitura inicial baseada na fonte oficial

Esta não é uma avaliação de uso pelo Viveiro. A fonte oficial apresenta o OpenRefine como uma ferramenta livre e de código aberto para trabalhar com dados desorganizados, com facetas, agrupamento de valores semelhantes, reconciliação com bases externas, histórico de desfazer e refazer e processamento local.

Parece adequado para preparar planilhas e outros dados antes da importação em um catálogo ou repositório. A avaliação prática deve verificar a qualidade das regras de transformação e reconciliação para cada conjunto de dados.
